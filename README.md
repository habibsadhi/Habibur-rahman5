# Digital Marketing, SEO & Graphic Design Portfolio

A professional, high-performance, fully responsive personal portfolio website crafted with **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS**.

Tailored specifically for showcasing **Search Engine Optimization (SEO)**, **Paid Digital Marketing & PPC Ads**, and **Brand Graphic Design**.

---

## 🌟 Key Highlights & Features

- **Pristine Light Theme UI**: Mathematical typography hierarchy (`Plus Jakarta Sans` & `Outfit`), clean whitespace, subtle borders, and high WCAG contrast.
- **Core Skill Pillars**:
  - **Search Engine Optimization**: Technical SEO, keyword clustering, Google Search Console, Schema markup, and Local SEO.
  - **Digital Marketing**: Meta (Facebook & Instagram) Ads, Google Performance Max PPC, funnel retention, and CRO.
  - **Graphic Design & Branding**: Vector logo systems, social media ad creatives, brand guidelines, and product packaging.
- **Interactive Features**:
  - **Marketing & SEO ROI Calculator**: Client-facing sliders for ad spend, traffic, and order value forecasting.
  - **Live SEO & Site Diagnostic Preview**: Instant check for crawlability, schema, and conversion tracking.
  - **Rich Case Studies Modal**: In-depth challenge, execution, deliverables, and quantifiable metric cards (+340% traffic, 4.52x ROAS).
  - **Visual Graphic Showcase**: Categorized lightbox gallery for design mockups and vector branding.
  - **Fast Contact Form**: Direct prefilled `mailto:` generator, copy-to-clipboard, and direct WhatsApp messaging.
- **GitHub Friendly**:
  - Fully modular architecture.
  - Single-file configuration: Edit all info in `src/data/portfolioData.ts`.
  - Zero server dependencies required for hosting on GitHub Pages, Vercel, or Netlify.

## 🚀 Quick Start & Customization

### 1. Clone & Install
```bash
# Clone the repository
git clone https://github.com/your-username/portfolio.git

# Navigate into project directory
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### 2. Customize Your Information
Open `src/data/portfolioData.ts` and modify:
- `personalInfo`: Name, email, bio, WhatsApp, social links.
- `heroStats`: Your personal project count, traffic records, and ROAS.
- `servicesData`: Specific offerings and tools you use.
- `caseStudiesData`: Your actual client results and screenshots.
- `graphicDesignShowcase`: Your graphic design images and clients.
- `testimonialsData`: Client reviews and quotes.

### 3. Build & Deploy to GitHub Pages or Vercel

```bash
# Build production bundle
npm run build
```
This generates a production-ready static build inside the `dist/` directory.

To deploy on **GitHub Pages**:
- Push your repository to GitHub.
- Go to your repository's **Settings** > **Pages**.
- Select **Deploy from a branch** (select `gh-pages` or set up GitHub Actions for Vite).

Or simply connect your GitHub repo to **Vercel** or **Cloudflare Pages** for automatic continuous deployment!
